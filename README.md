# 🦉 Nako // Project Vault & Omen Wing Legion Archives

Catalogue interactif et portail de projets hébergé sur **GitHub Pages**, fusionnant l'univers dynamique de **Nako** (Crimson Red) et l'aura mystique de **Omen Wing Legion [OWL]** (Cyber Teal).

Ce site permet d'explorer l'ensemble des créations (jeux en Lua / LÖVE 2D, modding Minecraft NeoForge, projets Unity, applications mobiles) avec un système avancé de **toggles de filtrage catégorisés** et une **transparence totale sur l'utilisation de l'IA**.

## ✨ Fonctionnalités Clés du Site Web

- 🎯 **Filtres par Toggles Catégorisés** :
  - **Statut** : *En cours*, *Terminé*, *En pause*, *Idée / Prévu*.
  - **Usage de l'IA** : *Sans IA (100% fait main)*, *Aide & veille*, *Code partiel*, *Complet*.
  - **Collaboration** : *Projet Solo*, *En équipe*.
  - **Technologies** : Tags dynamiques extraits automatiquement des projets (Lua, LÖVE 2D, Java, Unity, JS, etc.).
- 🔍 **Recherche temps réel** instantanée sur titre, résumé, description et technologies.
- 🦉 **Spotlight Omen Wing Legion [OWL]** : Carte vedette dédiée au projet communautaire majeur.
- 🌓 **Mode Sombre / Clair** immersif mémorisé dans le navigateur.
- 📊 **Tableau de bord statistique** calculé en direct.
- 📱 **100% Responsive Mobile** : Design soigné et sans débordement horizontal sur tous les écrans.
- ➕ **Générateur de projet JSON intégré** : Cliquez sur *"➕ Nouveau"* dans la barre de navigation pour générer facilement le snippet JSON.
